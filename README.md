# Product Photo Lab

Upload one product photo, pick a niche, get back 16 shots (12 environment + 4 lifestyle hand shots) at 2000x2000px. FastAPI backend + a single static HTML/JS frontend.

Deployed on Hugging Face Spaces (Docker SDK). Requires a `GEMINI_API_KEY` secret set in the Space's settings.

See [backend/README.md](backend/README.md) for local development setup.
